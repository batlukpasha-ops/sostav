# Состав

Веб-платформа формирования команд для стартапов и IT-проектов.
Специалисты находят проекты и откликаются на открытые роли, а авторы
публикуют свои идеи, приглашают специалистов и собирают команду.

Имя репозитория — `sostav`.

## Состояние проекта

Проект находится на этапе проектирования интерфейса и подготовки backend.

- Определены основные сценарии работы с проектами, ролями, откликами и приглашениями.
- Подготовлен интерактивный прототип из 26 экранов и состояний.
- Существующий учебный API реализует пользователей, профили, лайки и взаимные совпадения.
  Проекты, роли и участие в команде в backend пока не реализованы.

Прототип использует демонстрационные данные и не подключён к API.

## Технологии

Python, FastAPI, Pydantic, PostgreSQL, psycopg, SQL.
Прототип интерфейса написан на HTML, CSS и JavaScript.

## Локальный запуск API

Команды выполняются из корня репозитория. Требуются Python и PostgreSQL.

1. Создать виртуальное окружение и установить зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

2. Скопировать `.env.example` в `.env` и указать параметры своей базы:

   ```powershell
   Copy-Item .env.example .env
   ```

   Подключение задаётся переменными `DB_HOST`, `DB_PORT`, `DB_NAME`,
   `DB_USER`, `DB_PASSWORD` или одной переменной `DATABASE_URL`.
   Уже настроенный `.env` можно использовать с существующей базой.

3. Для новой локальной базы выполнить:

   ```powershell
   psql -U postgres -c "CREATE DATABASE sostav;"
   psql -U postgres -d sostav -f schema.sql
   psql -U postgres -d sostav -f demo.sql
   ```

   `schema.sql` пересоздаёт текущие учебные таблицы и удаляет их данные.
   `demo.sql` добавляет пять пользователей и их профили.

4. Запустить сервер:

   ```powershell
   uvicorn main:app --reload
   ```

Документация API: [Swagger UI](http://127.0.0.1:8000/docs).

## Текущие маршруты API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| POST | `/users` | Создать пользователя |
| GET | `/users` | Получить пользователей |
| GET | `/users/{user_id}` | Получить пользователя |
| POST | `/profiles` | Создать профиль |
| GET | `/profiles/{user_id}` | Получить профиль |
| POST | `/likes` | Поставить лайк |
| GET | `/matches/{user_id}` | Получить взаимные совпадения |

Эти маршруты относятся к учебной основе. API проектов, ролей, откликов
и приглашений будет добавлен по мере разработки платформы.
